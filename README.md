# Word Frequency Counter📜

A **Word Frequency Counter** application is a C program designed to analyze a text input, count the total number of words, and display the frequency of each word in descending order of occurrence.

## Features
- Reads and processes user-provided text input.
- Counts the total number of words in the text.
- Tracks the frequency of each unique word.
- Displays the results sorted by word frequency in descending order.

## How It Works
1. **Input:** The user types a block of text.
2. **Processing:** 
   - The text is tokenized using delimiters (e.g., spaces, punctuation).
   - Words are stored in a hash table for efficient lookups and counting.
3. **Output:** The program outputs:
   - Total number of words.
   - List of unique words and their respective counts, sorted by frequency.

## Technology Stack
- **Language:** C
- **Data Structure:** Hash table for word storage and frequency tracking.
